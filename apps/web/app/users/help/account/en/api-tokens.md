An API token lets a program reach the app on your behalf, without your password. Tokens live in the **API tokens** section of Settings.

## Creating a token

Click **Create token**, give it a name that says where it will be used (for example, "reports spreadsheet") and confirm.

> [!IMPORTANT]
> The token shows only once, right after it is created. Copy it and keep it somewhere safe: after that, neither you nor the app can see it again.

## Following and revoking

The list shows each token with the date it was created and the last time it was used. A token you do not recognise, or no longer use, can be deleted: the program that used it loses access at once.
