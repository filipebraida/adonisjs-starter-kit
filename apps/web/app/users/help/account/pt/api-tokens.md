Um token de API deixa um programa acessar o app em seu nome, sem a sua senha. Os tokens ficam na seção **Tokens de API** de Configurações.

## Criar um token

Clique em **Criar token**, dê um nome que diga onde ele vai ser usado (por exemplo, "planilha de relatórios") e confirme.

> [!IMPORTANT]
> O token aparece uma única vez, logo depois de criado. Copie e guarde num lugar seguro: depois disso, nem você nem o app conseguem vê-lo de novo.

## Acompanhar e revogar

A lista mostra cada token com a data de criação e a última vez que foi usado. Um token que você não reconhece, ou que não usa mais, pode ser excluído: o programa que o usava perde o acesso na hora.
